🎬 Premiere Pro 自動無音削除ツール
無料 · オープンソース · Premiere Pro 2024/2025 対応

無音部分を自動で一括カット
編集時間を大幅短縮

ffmpeg で無音区間を検出 → Premiere Pro のタイムラインから自動リップル削除。手作業ゼロで爆速編集が可能になります。

⬇ detect_silence.py ⬇ remove_silence.jsx
Mac / Windows 対応 Python 3 · ffmpeg のみ Premiere Pro 2024/2025

ツールの流れ

① 動画ファイル
→
② detect_silence.pyffmpegで無音を検出
→
③ silence.json無音区間リストを出力
→
④ remove_silence.jsxPremiere Proで自動カット
→
⑤ 完成 🎉

必要なもの

Python 3

Mac には最初から入っています。
Windows は python.org からインストール。

ffmpeg

Mac: brew install ffmpeg
Windows: winget install ffmpeg
または ffmpeg.org から。

Adobe Premiere Pro

2024 / 2025 対応。
タイムラインにアクティブなシーケンスが開いている状態で実行してください。

使い方（ステップごとの手順）

1

2つのファイルをダウンロードして同じフォルダに置く

上のボタンから detect_silence.py と remove_silence.jsx をダウンロードし、デスクトップなど分かりやすい場所に保存してください。

2

ffmpeg をインストールする（初回のみ）

ターミナル（Mac）またはコマンドプロンプト（Windows）を開いて実行：

# Mac（Homebrewが必要。未インストールの場合は brew.sh を先に参照）
brew install ffmpeg

# Windows
winget install ffmpeg
💡 インストール後、ffmpeg -version と打ってバージョンが表示されれば OK です。
3

無音区間を検出する

ターミナルでスクリプトを保存したフォルダに移動し、以下を実行：

python3 detect_silence.py 動画.mp4 silence.json

感度を細かく調整したい場合はオプションを追加できます：

python3 detect_silence.py 動画.mp4 silence.json \
  --min-silence 0.3 \    # 無音とみなす最小時間（秒）デフォルト: 0.5
  --threshold -35 \      # dBレベル（大きくすると感度UP）デフォルト: -40
  --padding 0.1          # カット前後に残す余白（秒）  デフォルト: 0.1
💡 実行すると同じフォルダに silence.json が生成されます。
4

Premiere Pro でシーケンスを複製しておく（推奨）

プロジェクトパネルのシーケンスを右クリック →「複製」。
万が一やり直したい場合に元データを保護できます。

5

Premiere Pro でスクリプトを実行する

Premiere Pro のメニューから：

ファイル → スクリプト → スクリプトファイルを実行
  → remove_silence.jsx を選択 → 開く

ファイル選択ダイアログが出たら silence.json を選択 → 確認画面で「OK」を押すと削除が始まります。

💡 クリップがタイムラインの 00:00:00 から始まっていることを確認してください。
6

完了！

「○○箇所の無音区間を削除しました」と表示されれば成功です。
削除しすぎた場合は Cmd+Z（Mac）/ Ctrl+Z（Windows）で元に戻せます。

うまくいかない場合

?

「ffmpeg が見つかりません」と出る

ffmpeg が正しくインストールされていません。ターミナルで brew install ffmpeg（Mac）または winget install ffmpeg（Windows）を再実行してください。

?

「無音区間が見つかりませんでした」と出る

--threshold の値を上げてみてください（例：--threshold -35 や -30）。録音環境によってノイズレベルが異なります。

?

カットされる位置がずれている

クリップがタイムラインの途中（例: 10秒目）から始まっている場合、remove_silence.jsx の1行目付近にある TIMELINE_OFFSET をその秒数に変更してください。

var TIMELINE_OFFSET = 10.0;  // 10秒目から始まる場合
?

「アクティブなシーケンスがありません」と出る

Premiere Pro でタイムラインのシーケンスをクリックしてアクティブにしてから、スクリプトを再実行してください。
